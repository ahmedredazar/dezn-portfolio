# DEZN Portfolio

## النشر على GitHub Pages

1. ارفع **كل الملفات** في جذر الريبو (مش جوه فولدر زيادة):
   - index.html
   - project.html
   - contact.html
   - architecture.html
   - architect.html
   - service.html
   - founder.html
   - style.css
   - script.js
   - ahmed-reda.jpg
   - .nojekyll

2. من الريبو على GitHub:
   - Settings → Pages
   - Source: **Deploy from a branch**
   - Branch: `main` (أو `master`) → folder: **/ (root)**
   - Save

3. استنى دقيقة أو اتنين، بعدين افتح:
   `https://USERNAME.github.io/REPO-NAME/`

## لو الصفحة بايظة

- تأكد إن `style.css` و `script.js` موجودين جنب `index.html` مش في فولدر تاني
- امسح الكاش: Ctrl+Shift+R
- افتح F12 → Console وشوف لو في أخطاء حمراء
- لو الريبو اسمه `username.github.io` حط الملفات في الجذر مباشرة

## هيكل الملفات الصحيح
